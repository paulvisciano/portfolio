Musical Cubes

Music as something you turn. Not a DAW timeline. One surface on web and mobile.

A timeline DAW is a list of channels you scroll. Musical Cubes is a set of tactile 3D cubes you turn. Each cube is a track. Each face is an instrument stem. Rotate to solo, mute, or rearrange. The mix changes in the room, not in a lane.

One product surface. Phone in the hand. Browser on the desk. Same cubes.

What it is

  • 3D track cubes. Rotate to switch stems and hear the mix change in real time.
  • Web + PWA + native. Ionic, React, Capacitor. One product across platforms.
  • Spatial first. Production as something you manipulate in space. Not only a list of channels.

Turn a cube. Hear the change. Layer sounds. You do not have to study a DAW first. Learn the cubes once. You know them. Live at paulvisciano.com/apps/musical-cubes.

What's next

The cube UI already scales into 3D space, the same way the other Sci-Fi Labs apps do. Several cubes in one environment, staying in sync. A cube as a distribution unit: one stem, or a set that already works together. Attribution stays with the stem. The instrument is the package.
