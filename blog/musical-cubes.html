Musical Cubes

Stop operating a DAW. Start turning an instrument.

Musical Cubes is an interactive music production app where tracks live as rotating 3D cubes. Each face is an instrument stem — piano, keys, brass, vocal, bass, guitar, drums — that you can play, loop, and sync in real time.

It was extracted from an earlier experiment, Musical Realms, and refined into a standalone instrument UI. The goal is simple: making sound should feel tactile and visual, not like managing a timeline.

How it works

  • 3D cube instruments — rotate to switch stems; each face has its own waveform to play, loop, and scrub
  • Sync across faces — stems share a playhead so layers stay in time; unlock a face for an independent loop
  • Track discovery — drop WAV packs into a folder; a build script registers them automatically
  • Cross-platform — one Ionic + Capacitor codebase as web app, PWA, and native iOS/Android
A Sci-Fi app: spatial interaction first — web and mobile today, immersive environments as the natural next surface.
