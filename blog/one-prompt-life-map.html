One prompt. Your own life map.

Paste this into Grok, drop your Google Maps Timeline export, and get a personal Where is [You]? — globe, timeline, markers, the works. The same idea behind Where is Paul?, now copy-paste ready.

Your location history is already sitting there

Google still holds (or once held) years of Timeline data. Most people never open the file. It sits as JSON full of places, timestamps, and the quiet record of where a life actually moved. The usual next step is nothing — or a spreadsheet, or a map that never becomes a product you can return to.

Where is Paul? started from the opposite decision: treat that record as first-class material for a spatial app. Globe, timeline, stories, filters. A navigable surface instead of a dump. The live version lives at paulvisciano.com/apps/where-is-paul. It is the proof that the pattern works.

The next step is making the pattern portable. One prompt. Your export. Your name on the title bar.

Copy the prompt below. Paste it into Grok. When the app is ready, drop in your Timeline export. That is the entire workflow.

The prompt

Everything below the line is meant to be copied as-is. Change the name if you want; leave the rest alone on the first run.

Hey Grok, build me a map like this one: https://paulvisciano.com/apps/where-is-paul and make it mine. Use the live site as the template. Then I'll drop in my Google Maps Timeline export and you can wire up my data automatically.

That is the whole ask. Grok builds the app. You feed it the export. The result is a personal life map that runs in the browser.

How to export your Google Maps Timeline data

Google moved most Timeline storage onto the device itself starting in late 2024. That means there are now two useful ways to get the data out. Do both if you want the fullest possible history.

1. On-device export (recent data)

This is the primary way to get trips recorded after the migration.

  • Android: Settings → Location → Location services → Timeline → Export Timeline data. You get a file named Timeline.json.
  • iOS: Open the Google Maps app → your profile picture → Settings → Location & Privacy (or Personal Content) → Export Timeline data → Save to Files.

2. Google Takeout (historical archive)

Still useful for older data that lived on Google’s servers before the on-device shift.

  1. Go to takeout.google.com and sign in.
  2. Click “Deselect all”.
  3. Find and select only Location History (Timeline).
  4. Choose JSON as the format and create the export.
  5. Google emails a download link (usually within minutes to a couple of hours). Unzip the archive.

Inside you will typically find Records.json, Settings, and a Semantic Location History folder with monthly files. Any of the JSON pieces can be useful; the semantic monthly files are often the cleanest for place visits.

Once you have the file (or files), drop them into the app the prompt generates. The generated code should attempt to parse the common shapes. If a particular format needs a small adjustment, you can ask Grok to update the parser.

Why this works

The hard parts of a spatial life map are the data model and the interaction model — how stays become markers, how time becomes a filter, how the globe stays readable. Those pieces are now described clearly enough that a single well-structured prompt can produce a working first version. The Google export is the fuel. Everything else is pattern matching against an existing reference (Where is Paul?) and ordinary web technology.

You still own the data. The export never has to leave your machine if you run the generated app locally. The published Where is Paul? site is the public demo; the private copy of the same idea, built from your own Timeline, is the version that actually belongs to you.
