Running Local AI on 16 GB Mac

16 GB M2 Pro. A 27B model. Whisper in. Browser still open. Conversation mode: 14.73 GB used, pressure green.

The goal

Talk to a local AI on my 16 GB Mac while still using it. Not a benchmark rig. The laptop I browse and code on.

You can run local AI on a 16 GB laptop. I did. 27B model, speech in, speech out, browser still open.

Idle, before any of that: 8.19 GB used. 565 processes. Most of them I didn't install. Extra processes eat memory the model could use. That's why I'd swap for an OS that only runs what I named — not a bunch of background stuff I've never heard of. That's for another time. Part 1.

Back to this laptop. Simpler setup than the last write-up — no RAG. I captured four states so we have a baseline: what local AI actually uses on this laptop, and how the memory is allocated:

  1. Idle. No models. 565 processes.
  2. Loaded. Model in memory, not talking yet.
  3. Text chat. Generating.
  4. Conversation mode. Whisper in, generating, still using the laptop.

Those four states ran on one stack: Open WebUI in the browser, llama.cpp serving Bonsai, Whisper in, Kokoro out. No Knowledge Graph. No LightRAG. No Docker, no embeddings server, no second llama slot. If you read the previous 16 GB budget, forget its process list — that was the older setup: Postgres, LightRAG, two model slots, Whisper as its own server. Different stack, different swap. Don't mix the two.

Hugging Face lists a 3.9 GB deployed footprint. That's the model file on disk. It doesn't count what else you have running, or the full memory once you talk to it — the conversation cache (KV cache) included. Every number from here on came off this machine, live.

Conversation mode

You talk into the laptop. Whisper is the speech-to-text model — it writes down what you said. It runs inside Open WebUI's Python process on this machine. The 27B model reads those words plus whatever rules you set, and writes a reply. Kokoro is the text-to-speech model — it reads that reply out loud in the browser. Five hops. None of it leaves the machine. Type instead of talk and you skip Whisper and Kokoro.

Whisper is why python3.12 reads 1.12 GB real in the capture. You don't load that when you type. It stays loaded between turns, so you pay it once per session, not once per sentence. Kokoro sits in that same Python process. Neither one is a second 27B on the GPU. The expensive part is still the 27B generating — talking or typing.

Loading the model is not the expensive part. Memory Used goes 8.19 → 11.27 GB. Compressed jumps 85.5 MB → 3.82 GB. Swap shows up: 2.68 GB. Pressure still green.

Talking to it is the jump. Wired goes 1.71 → 9.43 GB. The model file didn't get bigger. The laptop now has to remember every token of the conversation — that's the cache — and the GPU pins memory to actually compute. Loaded and idle, the model is a file sitting in memory. First reply, that working set gets locked down and stays as long as the model is warm.

Two readings that look like typos and are not. One: swap exists at all — 2.68 GB with pressure green. macOS compresses and swaps before the machine is in trouble. Swap on this box means the OS is making room, not failing. Two: swap drops from 3.11 GB (text chat) to 2.76 GB (conversation). These are not cumulative screenshots. Each was captured in its own moment. Conversation mode came later in the session, with slightly more of the working set back in physical memory. Read the trend, not the delta.

Whisper shows up as python3.12 real memory — 1.12 GB — not another 8 GB of GPU. Brave and a coding session stay in the list the whole time.

565 processes

MacBook Pro 14" (Mac14,9). Apple M2 Pro. 10-core CPU, 6 performance plus 4 efficiency. 16-core GPU, Metal 4. 16 GB unified memory. There is no separate VRAM. CPU, GPU, OS, and models share one pool. Every byte a model takes is a byte the browser is not using.

Idle, no models, this laptop is already running 565 processes. Finder, Safari, Activity Monitor — you can name those. mds_stores, sharingd, duetexpertd, siriinferenced, homed — I didn't install those. Almost all of them shipped in /System. You cannot uninstall most of them.

The pie is Memory Used at idle, 8.19 GB. Cached files (6.37 GB) sit outside it. Apps I opened are 9%. The rest is the OS.

Most of these live in /System. You cannot uninstall WindowServer. Hide Siri and siriinferenced still runs.

Load average 16.6 on a 10-core machine looks like a laptop on fire. It isn't. The consumers are mds and five mdworker_shared processes — Spotlight, reindexing after boot. The load will drop. The process count will not. Spotlight will finish. siriinferenced will not leave. That is a Mac at rest.

Those 565 names eat memory the model could use. I have not measured Omarchy on this desk.

Look at the four photos. Brave is open. A coding session is in the list. Spotlight never left. Conversation mode at 14.73 GB used of 16, pressure green. VS Code was not in these photos. I will not invent it. The headroom is there.
