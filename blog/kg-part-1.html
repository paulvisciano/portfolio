Knowledge Graph, Part 1: The canvas and the stack

Cut over to an infinite canvas, make time a depth axis, and run models that never leave the machine.

Knowledge Graph did not start as a polished spatial product. It started as a local stack that had to answer one question: can memory, photos, and voice live on your machine — and still feel like something out of a film, not a folder?

The early commits tell a clear story. The first decisive move was abandoning the force-directed graph view. 3d-force-graph and the d3 force/zoom/selection path were deleted in a single cut-over. In their place: an infinite Three.js canvas where time is a depth axis. Photos and later conversations would sit in buckets along Z — Today, Yesterday, This Month — so scrolling was no longer a list gesture. It was travel through time.

Cut-over day: remove the force-graph subtree (~3,500 lines), render CanvasView unconditionally, keep only the selected-node overlay. No dual-mode toggle. One surface.

Time has to be real

A canvas of time only works if dates are honest. Upload timestamps lied. EXIF did not. Bulk EXIF endpoints, typed columns for date_taken and dimensions, and layout code that preferred camera time over ingest time turned floating planes into a chronological filmstrip. Month buckets were spaced deliberately so each period was a distinct depth layer — not a stack of cards all visible at once.

Portrait photos rendered as landscape until the EXIF height tags were fixed. ExifImageLength mattered. Small details; without them the spatial metaphor collapsed into wrong geometry.

The two-phase pipeline

Image understanding could not block the UI. Phase 1: EXIF, faces, entity creation — fast enough to place a node. Phase 2: local VLM description into LightRAG, deferred and batchable. Metadata persisted so a restart could resume. VLM inputs were resized before base64 encoding; payload size dropped roughly fifty times with descriptions that stayed usable.

Docker memory limits were cut to match measured usage. start-all.sh became the single entry point: containers, then host Metal servers. Whisper moved to the host so it could use the GPU. Thumbnails stopped OOM-killing the API under the first-load burst.

The model that could run at home

Gemma gave way to Bonsai-27B in 1-bit form. Stock llama.cpp could not load the packed weights. The PrismML fork with custom Metal kernels became a hard dependency. Disk footprint dropped. Vision stayed local via mmproj. The promise was concrete: no cloud APIs for the core loop.

By late July the skeleton was honest. A private graph, a spatial canvas, models that never left the machine. What was missing was the feeling of living inside it — voice, mobile, and a chat surface that belonged to the same space as the photos.
