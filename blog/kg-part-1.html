Knowledge Graph, Part 1: The canvas and the stack

Cut over to an infinite canvas, make time a depth axis, and run the whole stack on 16GB of shared memory — models that never leave the machine.

Knowledge Graph started as a bet that memory should be a place, not a thread. The first solid version of that bet was a Three.js infinite canvas with time as a navigable dimension, local models for vision and speech, and a pipeline that kept originals on hardware you own.

Why a canvas

Lists and chat windows flatten life into sequence. A spatial surface lets the same day hold photos, notes, and later conversations without forcing them into a single scroll order. Zoom out for months; zoom in for an afternoon. The camera is the primary navigation, not a sidebar of folders.

Local by default — on 16GB shared

Models run on Metal. Whisper, vision, embeddings, the graph, Postgres, and the canvas all share one machine. There is no obligatory cloud ingest to make the product work — cloud is optional, not the path of least resistance.

The ultimate test for sovereignty is offline. Airplane mode. No Wi‑Fi. No fallback API. If the assistant still answers from weights on disk and data on disk, it is a local model in fact — not a thin client dressed up as “AI on your machine.” Anything that silently phones home when the cable is unplugged has already failed the test.

The hard constraint is not “local in theory.” It is running the entire stack in about 16GB of shared memory: unified CPU and GPU memory on the same laptop, with the OS, browser, and app already taking their cut. LLM weights, Whisper, vision, and the live canvas compete for the same pool. That budget is why quantization, idle reclaim, and careful load order are product decisions — not optimization trivia.

One of the main challenges of this series is that sovereignty has a hard ceiling: the whole stack has to fit and stay usable in 16GB of shared memory — and keep working with the internet unplugged. If it only works when a vendor’s API is up, it is not a private memory system.
