Knowledge Graph, Part 3: A living interface

Component extraction, design tokens, timeline as dimension, and the Sci-Fi Labs frame for a sovereign memory surface.

With the stack stable and voice online, the commits shift tone. Extraction, design tokens, docks, and a clearer public story.

From monolith to components

The main page had grown past three thousand lines. ChatPanel was extracted into its own component; the page became a thin orchestrator. Open Design HTML prototypes tracked the Svelte surfaces — CanvasView, NodeOverlay, ProcessingDock, NavDrawer — so visual work could move without fighting the full app. oklch semantic tokens replaced ad-hoc hex values. Message bubbles, thinking blocks, tool summaries, and stream cursors got a coherent language.

ProcessingDock moved to the bottom-right and learned to poll the API, hide completed work, and offer reprocess on failure. Photo nodes stopped jumping time buckets: creation waited until EXIF arrived. The timeline became navigation, not a filter — Today and Yesterday as first-class buckets, not special cases bolted on.

What the graph is for

Under the chrome, the knowledge loop tightened. Date queries stopped relying on slow LLM keyword extraction; NLP shortcuts and post-filters kept same-day photos and notes together. Notes got their own plane kind so diary text was not misrouted as photos. MCP tools could save and query; the model was instructed to call tools when it claimed to, and to avoid emoji and save-language during retrieval. Q1 quant loops were fought with penalties, caps, and occasional sampler experiments.

None of that is glamorous. All of it is why asking “what did I do last week” can return a day of photos and conversation instead of a generic summary.

Sovereignty is not a tagline here. Models run on Metal. Graph, Postgres, and Whisper stay on hardware you control. Public surfaces are chosen, not default.

The interface you were told belonged to movies

August closed with portfolio images, a spatial AR still, README vision language, and the Sci-Fi Labs frame shared with Where is Paul? and Musical Cubes. The product direction is explicit: glassy panels, hierarchical expansion, time as a navigable dimension, ambient presence instead of a transactional chat window — first on web and local machines, with the same spatial grammar meant for XR.

The Git log is not a release note. It is a record of choosing local over convenient, spatial over list, and persistence over demo. Knowledge Graph is still a living system. The three parts of this series are the path that made that choice legible: a canvas of time, a voice that works offline, and an interface that treats memory as a place you move through.
