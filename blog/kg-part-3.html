Knowledge Graph, Part 3: A living interface

Extraction, design tokens, better answers from the graph, and the Sci-Fi Labs frame for a sovereign memory surface.

With the stack stable and voice online, the commits change character. Extraction, design tokens, docks, query quality — and a public story that finally matched the private ambition.

From monolith to something you can change

The main page had grown past three thousand lines. ChatPanel became its own component; the page became a thin orchestrator. Open Design HTML prototypes tracked CanvasView, NodeOverlay, ProcessingDock, NavDrawer so visual work could move without fighting the full app.

oklch semantic tokens replaced ad-hoc hex. Message bubbles, thinking blocks, tool summaries, and stream cursors shared one language. ProcessingDock moved to the bottom-right, learned to poll the API, hide finished work, and offer reprocess on failure. Photo nodes stopped jumping time buckets: creation waited until EXIF arrived. The timeline became navigation, not a filter — Today and Yesterday as first-class buckets.

Why the graph answers better

Direction is wasted if asking “what did I do last week” returns a shallow summary. Date queries stopped relying on slow LLM keyword extraction; NLP shortcuts and post-filters kept same-day photos and notes together. Notes got their own plane kind so diary text was not misrouted as photos. MCP tools could save and query; the model was instructed to actually call tools when it claimed to, and to avoid save-language during retrieval. Q1 quant loops were fought with penalties, caps, and sampler experiments.

None of that is glamorous. All of it is why the spatial metaphor earns trust: the place you travel through contains real days, not marketing placeholders.

Sovereignty is not a tagline. Models run on Metal. Graph, Postgres, and Whisper stay on hardware you control. Capture metadata — the EXIF log of when and where — is read from files that never passed through a messaging app or cloud export that strips it. Public surfaces are chosen, not default.

Inspiration, closed loop

The infinite-canvas tradition on GitHub — from handwritten notes to agent workspaces — proved that unbounded surfaces can carry serious work. Knowledge Graph takes that tradition into sovereign memory: not a collaborative whiteboard, but a private palace where time is the primary dimension and the AI is ambient rather than a modal chat box.

August closed with portfolio images, an AR still, README vision language, and the Sci-Fi Labs frame shared with Where is Paul? and Musical Cubes. The product direction is explicit: glassy panels, hierarchical expansion, ambient presence — first on web and local machines, with the same spatial grammar meant for XR.

The Git log is not a release note. It is a record of choosing local over convenient, spatial over list, and persistence over demo — and of optimizing until that choice felt natural in the hand. Knowledge Graph is still a living system. These three parts are the path that made the change of direction legible: a canvas of time, a voice that works offline, and an interface that treats memory as a place you move through.
